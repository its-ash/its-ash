### Engineering Principles

- **Ship working software.** A deployed solution beats a perfect plan.
- **Measure, then optimize.** Profile first. Optimize what the data shows.
- **Right tool for the job.** Rust for speed and safety, JavaScript for the web, Python for velocity.
- **Design for the next engineer.** Clear boundaries, explicit contracts, readable code.
- **Low operational cost.** Fewer moving parts, predictable failures, observable systems.

### Featured Work

#### [Ash Tools](https://ash-tools.store/) · [source](https://github.com/its-ash/ash-tools)

A privacy-first suite of browser tools for media, documents, and developer workflows. All processing runs on the client — files never leave the device.

- **Stack:** JavaScript front end, compute-heavy work in WebAssembly and WebGPU, static deployment on Cloudflare Pages.
- **Tools:** Video Studio, Image Editor, PDF Merger, Regex Generator, Code Sandbox.
- **Result:** zero server-side data handling, no upload latency, no backend to operate.

More projects: [its-ash.github.io/project.html](https://its-ash.github.io/project.html)
